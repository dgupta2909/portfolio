# Devanshu Gupta — Neon Professional Portfolio

A functional engineering portfolio recreated from the supplied visual reference as a **website design**, not as an image background.

### Visual direction
- Black, charcoal and neon-purple atmosphere
- Purple glow clouds and diagonal light streaks
- Perspective neon floor grid
- Grain/noise texture and cinematic vignette
- Large condensed/editorial typography
- Dark poster-like hero card
- Neon accent buttons and borders

### Functional
- Responsive navigation
- Cursor interaction
- 3D hover cards
- Scroll progress
- Reveal animations
- Project category filters
- Project detail modal
- Functional mailto contact form
- Responsive mobile layout
